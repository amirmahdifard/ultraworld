# ultra world

this is a survival online audiogame created for the blind using NVGT. https://nvgt.dev

## where things are.

Client/ is the client code, with the client/includes folder holding scripts that the client uses. The main client entry point is client/uw.nvgt. this is how you run the game.

Server/ Contains the server code, with server/includes/ holding the server include scripts. the server entry point is server/uwserver.nvgt.

The server folder also contains many folders with data for the game. This includes server/ais, foods_and_drinks, ntm, rules, and changelogs. There are also many .json files in the server folder.

## About the game.

Ultra world is a online survival game that combines fps ideas. You can get a house, fight dragons, and hunt rabits, all in the same game.
